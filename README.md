# Retail Sales SQL Analysis

## Project Overview

Analyzed Superstore retail sales data using Python, Pandas, SQLite, Matplotlib, and Seaborn.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite3
- Jupyter Notebook
- Git

## Analysis Performed

### EDA
- Data Cleaning
- Revenue by Category
- Top Products Analysis
- Regional Sales Analysis
- Profit Analysis
- Monthly Trend Analysis

### SQL Analysis
- Top 10 Products by Revenue
- Highest Profit Category
- Monthly Sales Trends
- Customer Segmentation
- Regional Performance
- Loss Making Products

## Key Findings

- Total Revenue: $2.29M
- Total Profit: $286K
- Technology generated the highest revenue.
- Canon imageCLASS 2200 Advanced Copier was the highest revenue product.
- Several products generated negative profit despite strong sales.
